# Free Browser Games for All

A Neal.fun-inspired directory of **50 curated browser games**.

- 50 games
- playful, game-specific tiles
- category filters
- responsive mobile layout
- links go directly to the game/creator page
- selection focuses on genuinely free, ad-free browser games rather than ad-heavy game portals

Main no-ad sources used for the collection include independent creator pages plus Driftmoth Games, PlayNeon, Match Heist and AnywherePlay.

> Ad policies can change after publication, so the live site includes a small status note.
